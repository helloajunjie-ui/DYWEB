# DYweb 场控中枢 · 使用说明（v0.1 原型）

> 双击 `启动.bat` 就能用。控制台：<http://127.0.0.1:9101/>　舞台层：<http://127.0.0.1:9101/overlay>

---

## 1. 它是什么

一个**本地小服务**：第三方弹幕工具把直播间事件推到本机端口，它负责把事件变成声音、画面和外部动作。

```
第三方弹幕工具 ──POST JSON──► 本机 9101 端口
                                  │
                     规则匹配（关键词/礼物/金额/连击/冷却）
                                  │
        ┌───────────┬────────────┬┴──────────┬───────────┐
     本机 TTS     舞台层特效     音效        Webhook     模拟按键
    （出声）     （OBS 浏览器源） （本机+页面）（灯光/机械）  （整蛊）
```

不需要登录、不逆向平台、不联网也能跑（只有 AI 话术需要联网）。

---

## 2. 第一次启动

1. 双击 `E:\DYweb\启动.bat`。
2. 浏览器自动打开控制台（没打开就手动访问 `http://127.0.0.1:9101/`）。
3. 顶部显示 **已连接引擎**，说明后端在跑。

关闭服务：任务管理器结束 `dyweb.exe`，或命令行 `taskkill /IM dyweb.exe /F`。

端口被占用时：编辑 `data\config.json` 的 `"port"`，或用 `dyweb.exe -port 9300` 启动。

---

## 3. 五分钟跑通（不接直播间也能验）

1. 进 **调试台** → 类型选「礼物」→ 观众填「测试大哥」→ 礼物名「嘉年华」→ 单价 3000 → 点 **发送事件**。
2. 回到 **总览**：事件流出现一条，动作日志出现 4 行（TTS、横幅、音效、烟花合并）。
3. 此时本机扬声器应该有声音（Windows 中文音色，没装中文语音包会念得怪）。
4. 点右上角 **打开舞台层**，页面是透明的，点一下「点击启用声音」。
5. 调试台点「烟花 / 爱心雨 / 横幅」，舞台层立刻出画面。

**OBS 接入（关键一步）**

- 来源 → 添加 → **浏览器** → URL 填 `http://127.0.0.1:9101/overlay`
- 宽高 `1920 × 1080`，勾选「使用自定义帧率」60
- 勾选 **关闭源时关闭…** 不需要；必须勾 **「控制音频」之外** 的自动播放：
  - OBS 浏览器源默认允许音频，若无声：右键源 → 属性 → 勾选「音频」相关（不同版本叫法略异），或先在浏览器里点一次「启用声音」。
- 想要透明背景：浏览器源默认透明，不要把网页背景改成不透明即可。
- 调试时给 URL 加 `?debug=1` 可以看到 WS/FPS/粒子数面板。

## 4. 接第三方弹幕工具

### 4.1 三种推法（任选）

| 方式 | 地址 | 说明 |
|---|---|---|
| HTTP POST | `http://127.0.0.1:9101/push` | body 是 JSON，最常用；也支持数组、`{"events":[...]}` |
| HTTP GET | `http://127.0.0.1:9101/push?data=<URL编码的JSON>` | 只能填 URL 的工具用这个 |
| WebSocket | `ws://127.0.0.1:9101/ws/ingest` | 长连接，消息同 HTTP body |

监听在 `0.0.0.0`，所以**同局域网的另一台机器也能推**（比如游戏机推事件给主机）。

### 4.2 最小字段（能被认出来就行）

```json
{"type":"danmaku","user":"阿猫","text":"主播好呀"}
{"type":"gift","user":"大哥张","giftName":"小心心","giftCount":6,"giftValue":1}
{"type":"enter","user":"老粉李"}
{"type":"follow","user":"路人王"}
{"type":"fansclub","user":"新粉小李"}
{"type":"guard","user":"守护大哥","guardLevel":2}
```

> `guard` 是开通/续费星守护，`guardLevel` 填 1~3；`fansclub` 是加入粉丝团；`follow` 是关注主播。
> 工具里如果没这些字段也没关系，规则不写这些类型就不会触发。

### 4.3 工具字段不一样怎么办

打开 **贴原始 JSON**（调试台右侧）→ 粘贴工具真实推的一条 → 看解析结果对不对。

不对就去 **设置 → 字段映射**，往对应字段的候选路径里加一条。路径用点号取嵌套，忽略大小写，找不到会自动进 `data` 容器里找：

```json
"user":   ["user", "nickname", "data.user.nickname", "Data.User.NickName"],
"text":   ["text", "content", "data.content"],
"giftName": ["giftName", "gift", "data.gift.name"]
```

保存后**重启 exe** 生效。

### 4.4 常见第三方工具形状（已在原型里实测过）

```json
{"Type":2,"Data":{"User":{"NickName":"大哥张","Id":"9001"},
 "Gift":{"Name":"小心心","RepeatCount":6,"DiamondCount":1}}}
```

→ 解析为：类型 gift、观众 大哥张、礼物 小心心 ×6、单价 1、总额 6。

## 4.5 先选直播定位（做这一步，后面都省事）

打开控制台，右上角有 **直播定位** 三个小按钮，点一下就行（不用输任何东西）：

| 按钮 | 什么时候选它 | 它会替你做什么 |
|---|---|---|
| 娱乐 | 你一个人在播，靠弹幕、礼物、整活撑场 | 总览显示礼物感谢 / 冷场救场 / 整活三条提示；话术库默认停在「留人 · 破冰」；功能中心把 TTS、AI 话术、观众画像、特效、音效、模拟按键标成「本模式推荐」 |
| 无人 | 人不常在镜头前，AI 主导说话 | 提示先开「特效合并防刷」「帧率护栏」，规则冷却放长；话术库默认停在「冷场 · 救场」 |
| 电商 | 卖货，AI 当助播 | 提示先录产品库、开主推商品；话术库默认停在「促单 · 算账」 |

切完立刻生效，配置存在 `data/config.json` 的 `mode`（`fun` / `auto` / `ecom`），重启后还是上次那个。总览顶部会显示当前定位的说明和三条提示，不用记。

## 5. 功能中心：按分类开关

进 **功能中心**，能力按七类摆开：接入 / 话术 AI / 画面特效 / 互动玩法 / 声音 / 硬件联动 / 运维自愈。

- 关掉某个模块 = 关闭这项能力，规则里引用它的动作会被跳过并记日志（不报错）。
- 每个可用模块带 **试一下**，不写规则也能验证设备通不通。
- 标「路线图」的是还没实现的（推币机、物理挂件、OBS、Hue 等），开关不可用。

## 6. 规则怎么写

**不用写代码，也不用写 JSON。** 进 **规则** 页 → 点右上「新建规则」→ 按格子填完 → 「确定」→ 「保存全部」。就这么四步。

表单里只有这几样：

| 格子 | 填什么 |
|---|---|
| 规则名 | 自己认得的名字，比如「大礼物放烟花」 |
| 什么时候触发 | 下拉选：有人送礼物 / 发弹幕 / 进直播间 / 关注 / 加入粉丝团 / 开星守护 / 点赞 |
| 说的什么词 | 只在「发弹幕」时出现，弹幕里包含这几个字就触发（如 `点什么`） |
| 指定礼物 | 只在「送礼物」时出现，留空 = 任何礼物；多个用「、」隔开 |
| 礼物价值门槛 | 只在「送礼物」时出现，填 300 表示 300 币以上才触发，0 = 不限 |
| 两次触发最短间隔 | 秒数，防止连刷刷爆（默认 3 秒） |
| 触发后做什么 | 打勾多选：语音播报 / 画面特效 / 大字横幅 / 音效 / AI 生成台词 / 模拟按键 / 调用一个网址 |

打勾之后会多出一个格子：选特效就多一个特效下拉（烟花、爱心雨、流星、彩带、抖动、聚光灯）和持续时长；选横幅就多一个横幅文字框，里面可以写 `{user}` `{gift}` 这些变量；选音效就多一个音效下拉（`sfx/` 目录里有什么就列什么）。

> 两条规则都满足时**会都触发**（比如「≥300 币」和「≥500 币」会同时放两次烟花）。不想重复就只留一条，或者把门槛错开。

### 6.0 高级：直接改 JSON

真要精细控制（比如连击累加、正则匹配、指定观众），点编辑框右上「高级（直接改 JSON）」。下面这套是 JSON 的完整字段，平时用不到。

```json
{
  "id": "r_big_gift",
  "name": "大礼物：烟花+横幅",
  "enabled": true,
  "priority": 30,
  "cooldownMs": 5000,
  "match": {
    "types": ["gift"],
    "giftNames": [],
    "minValue": 300,
    "minCount": 1,
    "minLevel": 0,
    "comboWithinMs": 0,
    "onlyRegular": false
  },
  "actions": [
    { "type": "effect", "preset": "fireworks", "durationMs": 6000, "merge": true },
    { "type": "banner", "template": "感谢 {user} 的 {gift} × {count}", "durationMs": 6000, "color": "#FFD24A" },
    { "type": "sound",  "file": "boom.wav", "volume": 0.85 },
    { "type": "tts",    "template": "{user}送出{gift}，全场给大哥让让道！" }
  ]
}
```

匹配字段（全为 AND，空值 = 不限）：

| 字段 | 含义 |
|---|---|
| `types` | 事件类型：danmaku / gift / like / enter / follow / guard（星守护）/ fansclub（粉丝团） |
| `keyword` + `keywordMode` | 弹幕文本：contains / equals / prefix / regex |
| `giftNames` | 礼物名，包含匹配（可写「嘉年华」「火箭」） |
| `minValue` / `minCount` | 礼物单价 / 数量下限（抖币） |
| `minLevel` | 观众等级下限 |
| `userName` | 指定观众（昵称包含） |
| `comboWithinMs` | 连击窗口：同人同礼物窗口内累加，`{combo}` 是累计数 |
| `onlyRegular` + `regularMin` | 仅老粉（互动 ≥ N 次，默认 5） |

动作类型：

| type | 参数 | 说明 |
|---|---|---|
| `tts` | `template` | 念话术 |
| `sound` | `file` `volume` | 播 `sfx/` 里的音频（wav 本机直放，其它走页面） |
| `effect` | `preset` `durationMs` `merge` | 特效：fireworks / hearts / meteor / confetti / shake / spotlight |
| `banner` | `template` `durationMs` `color` | 大字横幅 |
| `webhook` | `url` `method` `template` `headers` | 调外部服务，body 用模板渲染 |
| `llm` | `llmPrompt` | 调 AI 生成台词，并自动播报 |
| `hotkey` | `keys` | 模拟按键：`ctrl+space`、`f5`、`ctrl+shift+a` |

模板变量：`{user}` `{text}` `{gift}` `{count}` `{value}` `{total}` `{level}` `{guard}` `{combo}` `{fanNote}` `{time}`

**三条现成可抄的规则**

```json
// 1) 弹幕关键词触发整蛊：发"跳一下"就按空格
{ "name": "弹幕整蛊", "enabled": true, "cooldownMs": 3000, "priority": 20,
  "match": { "types": ["danmaku"], "keyword": "跳一下", "keywordMode": "contains" },
  "actions": [ { "type": "hotkey", "keys": "space" },
               { "type": "tts", "template": "{user}让你跳一下" } ] }

// 2) 礼物触发灯光（ESP32 / 继电器 / Hue 网关都收 JSON）
{ "name": "火箭变灯", "enabled": true, "cooldownMs": 2000,
  "match": { "types": ["gift"], "giftNames": ["火箭"] },
  "actions": [ { "type": "webhook", "url": "http://192.168.1.50/relay", "method": "POST",
                 "template": "{\"ch\":1,\"action\":\"flash\",\"ms\":300}" } ] }

// 3) 老粉进场提醒（备注来自观众画像）
{ "name": "老粉进场", "enabled": true,
  "match": { "types": ["enter"], "onlyRegular": true, "regularMin": 5 },
  "actions": [ { "type": "tts", "template": "真爱粉{user}进场了。{fanNote}" },
               { "type": "banner", "template": "{user} 来啦", "durationMs": 4000, "color": "#7ED0FF" } ] }
```

`cooldownMs` 是同一规则两次触发的最小间隔；`merge: true` 让特效在 1 秒内合并成一次（防连刷炸画面）。

### 6.1 礼物库（价目表）

很多第三方工具只推「礼物名 + 数量」，不推单价。系统会拿 **礼物库** 自动查价，再算 `{value}` / `{total}`：

- 内置 294 个抖音礼物价目（玫瑰 1、小心心 1、跑车 1200、嘉年华 30000…），单价口径为钻石（与抖币 1:1）。
- 进 **礼物库** 页可以搜索、改价、新增、删除，点「保存全部」写进 `data\gifts.json`。
- 工具推来新礼物时：点 **批量粘贴导入**，直接粘「礼物名 单价」一行一个（粘抖音的价目表原文也行，带「钻石」后缀会自动去掉）。
- 查价先精确匹配，再包含匹配（「蝶连理枝」也能命中「蝶·连理枝」）；工具推了单价就以工具为准，推的是 0 才查表。

## 7. 观众画像

每次弹幕/礼物/进场都会累计到 `data/fans.json`：互动次数、礼物次数与消费、首末次时间；互动 ≥ 5 次自动标「老粉」。

在 **观众画像** 页点「备注」写一句话（比如「上周过生日，爱听《晴天》」），之后规则里的 `{fanNote}` 就会念出来。

## 8. AI 话术（可选）

**设置 → AI 话术**，只有三步，模型名不用自己敲：

1. 点服务商按钮：`DeepSeek` / `火山方舟` / `阿里通义` / `本机 Ollama` —— 地址自动填好
2. 粘上你的 API Key
3. 点「自动获取模型」→ 模型那一格变成下拉框，系统自动选好一个；再点「测试连接」，出现「通了！模型回你：在的」就成功
4. 最后右上角「保存设置」

如果哪步错了，它会用中文告诉你错在哪：Key 不对会说「API Key 不对或已失效」；地址写错会说「地址写错或模型名不存在，BaseURL 一般以 /v1 结尾」；余额没了会说「账户余额不足」。

| 项 | 说明 |
|---|---|
| 地址 | 点服务商按钮自动填；一般以 `/v1` 结尾 |
| API Key | 从服务商控制台复制；本地 Ollama 留空 |
| 模型 | 点「自动获取模型」后从下拉选，不用记名字 |
| 超时 | 默认 8000 毫秒，网络慢就调到 10000 |
| System Prompt | 人设与红线（默认已写好「亲切有梗、不解释、不超过 30 字」，新手不用动） |

**已实测可用的一组配置**

```
服务商   DeepSeek
地址     https://api.deepseek.com/v1
模型     下拉里自动出现的那个（本次实测拿到 deepseek-flash / deepseek-v4-pro）
Key      sk-xxxx（DeepSeek 控制台申请）
超时     8000
```

实测链路：弹幕「主播点什么歌好」→ 规则命中 → DeepSeek 返回「点首《孤勇者》吧，让主播证明一下自己不是只会喊麦」→ 本机 TTS 念出来，耗时约 0.6 秒。

> 两个坑：①光填 Key 还不够，**「AI 话术」模块**必须开着，否则规则里的 `llm` 动作会被跳过（现在保存配置时如果 AI 已启用，会自动帮你打开这个模块）；②Key 以明文存在 `data\config.json`，别把这个文件发给别人，泄露了就去控制台重置。

规则里用 `llm` 动作即可，例如关键词「点什么」→ AI 推荐一首歌：

```json
{ "type": "llm", "llmPrompt": "观众说：{text}。用一句有梗的话回应，可以推荐一首歌。" }
```

## 9. 排错

| 现象 | 原因 / 处理 |
|---|---|
| 控制台顶部红点「连接中断」 | exe 没跑或端口不对；看 `data\run.err.log` |
| 事件不进来 | 工具推的地址要带 `/push`；先看调试台「贴原始 JSON」解析结果 |
| 字段全是空 | 字段映射没配；按 §4.3 加路径后重启 |
| 没声音 | 设置里 TTS 是否启用；没装中文语音包 → 换音色或改「页面朗读」 |
| 舞台层没画面 | 特效模块被关；OBS 里 URL 有没有写 `/overlay`；加 `?debug=1` 看 WS 是否 OK |
| 舞台层是白底 | 浏览器直接看是白底正常；OBS 浏览器源里是透明的 |
| 按键没反应 | 目标窗口要在前台；有反作弊的游戏会拦截 SendInput |
| 端口被占 | 改 `data\config.json` 的 port 或 `-port` 参数 |
| 360/杀软拦 exe | Go 单文件 exe 常被误杀，加白名单 |

日志：`data\run.log`（正常输出）、`data\run.err.log`（报错）。

## 11. 已知边界（原型阶段）

- 不主动抓抖音协议：必须有第三方工具把事件推过来（这是刻意的，规避风控与协议变动）。
- TTS 用 Windows 本机语音，音色有限；高质量音色/音色克隆在路线图里（`cloud_tts`、`voice_clone`）。
- 特效是 canvas 粒子，不是视频素材；绿幕/鬼畜素材叠加在 `fx_media`（路线图）。
- 推币机、阵营拔河、宝箱、木鱼、物理挂件、OBS 联动这些都还没实现，模块会显示「路线图」。
- 单人本机运行，没做多机同步与鉴权；不要把这个端口直接暴露到公网。
